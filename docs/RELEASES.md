# Release Management & Versioning

GeoMeasure uses [Semantic Versioning 2.0.0](https://semver.org/): `MAJOR.MINOR.PATCH`

- **Major (1.0.0)**: Initial baseline spatial measurement engine architecture and foundation.
- **Minor (1.1.0)**: Added native ARKit / ARCore bridge and offline CAD export features.
- **Patch (1.0.1)**: Precision bug fixes or minor performance optimizations.
