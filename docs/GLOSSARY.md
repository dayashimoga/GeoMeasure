# Glossary

| Term | Definition |
|------|-----------|
| **ARCore** | Google's Augmented Reality SDK for Android |
| **ARKit** | Apple's Augmented Reality SDK for iOS |
| **Clean Architecture** | Software design separating Presentation, Domain, Data, and Platform layers |
| **DLT** | Direct Linear Transform — method for 3D point triangulation from 2D correspondences |
| **DXF** | Drawing Exchange Format — AutoCAD vector file format |
| **EKF** | Extended Kalman Filter — sensor fusion algorithm |
| **FAR** | Floor Area Ratio — total floor area divided by plot area |
| **FAST** | Features from Accelerated Segment Test — corner detection algorithm |
| **GeoJSON** | RFC 7946 — geographic data interchange format |
| **Guntha** | Indian land measurement unit (≈101.17 m²) |
| **Haversine** | Great-circle distance formula for spherical Earth |
| **Hive** | Lightweight, fast key-value database for Flutter |
| **IoU** | Intersection over Union — overlap metric for bounding boxes |
| **KML** | Keyhole Markup Language — Google Earth format |
| **LiDAR** | Light Detection and Ranging — laser-based depth scanning |
| **ML Kit** | Google's on-device machine learning SDK |
| **NCC** | Normalised Cross-Correlation — image patch similarity metric |
| **NMS** | Non-Maximum Suppression — duplicate detection removal |
| **RTK** | Real-Time Kinematic — centimetre-accuracy GPS correction |
| **Shoelace Formula** | Algorithm for polygon area from vertex coordinates |
| **SLAM** | Simultaneous Localisation and Mapping |
| **Sobel** | Edge detection operator using gradient convolution |
| **ToF** | Time of Flight — depth sensing via light pulse timing |
| **UWB** | Ultra-Wideband — precise indoor positioning technology |
| **Vincenty** | Iterative geodetic distance formula for ellipsoidal Earth (WGS-84) |
| **WGS-84** | World Geodetic System 1984 — GPS coordinate reference system |
